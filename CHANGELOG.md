# Explorer Title Bar Label changelog

## 1.0.0

- Initial release.
- Added custom text to the Windows 11 File Explorer title bar.
- Added configurable date and time display.
- Added 12-hour and 24-hour time formats with optional seconds.
- Added customizable font, size, weight, color, opacity, and spacing.
- Added live updates.
- Compatible with Windows 11 File Explorer Styler and other Explorer XAML mods.
